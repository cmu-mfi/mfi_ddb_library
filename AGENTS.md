# AGENTS.md

Instructions for AI coding agents working in this repository.

**Before writing any code, read [CONTRIBUTING.md](CONTRIBUTING.md).**
Every rule in it is mandatory and applies to you.

Follow it for every task, and re-read it before declaring the task complete.

## Working on contributions

When the user starts a new contribution or edits, work in a new branch with
the goal of creating a PR. During planning, ask the user which type of PR it
is (feature, enhancement, bug fix, data adapter, ...), and include the
checklist from the corresponding PR template in
`.github/PULL_REQUEST_TEMPLATE/` in your plan.
